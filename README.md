# React To-Do List App 📝

A modern, responsive, and animated **To-Do List App** built with **React**, **Axios**, and **React Icons**.  
This project allows users to create multiple to-do lists, add and manage items, and enjoy a clean, glassmorphism-inspired UI.

---

## 🌟 Features

- **Multiple To-Do Lists**: Create, delete, and manage multiple lists.
- **Item Management**: Add, check/uncheck, and delete individual items.
- **Animated UI**: Smooth hover effects, slide-in animations, and button interactions.
- **Glassmorphism Design**: Clean glass-style panels with soft shadows.
- **Responsive**: Works beautifully on desktop and mobile devices.
- **Custom Scrollbars**: Styled scrollbars for better UI consistency.
- **Modern Color Theme**: Teal/blue gradient background with readable text.

---

## 🛠️ Technologies Used

- **React** – Frontend library for building components.
- **Axios** – HTTP client for communicating with REST API.
- **React Icons** – For trash and other icons.
- **CSS3** – Glassmorphism, animations, and responsive layout.
